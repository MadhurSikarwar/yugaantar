# Trust, but verify: post-quantum protected files with verifiable decisions

Yugaantar DevForge, Track 4.

This branch holds the web console only (`frontend/`).

## Run

Needs Node.js 22.18+ or 24.

```sh
cd frontend
npm ci
npm run dev
```
